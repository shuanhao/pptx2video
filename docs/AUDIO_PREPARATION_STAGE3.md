# Stage 3：Prepared 音訊的 anchor 與退回處理

> 設計更新：音訊準備已改為同層固定檔名、每次全部重轉，移除 `--force-prepare-audio` 與快取重用。以下關於版本化、整批回復與重用的敘述保留為歷史紀錄；現行規則見 [音訊準備手冊](AUDIO_PREPARATION.md)。舊驗收結果不等同新版已通過驗收。


此階段已完成 prepared 音訊定位、明確時間映射與退回狀態傳遞。三份字幕及結構化 JSON 診斷檔由 Stage 4 完成；目前透過回傳 records 與警告提供診斷資訊。尚未進行真實 PowerPoint 全功能驗收。

## 適用範圍與介面

`locate_slide_alignments()` 回傳逐頁 records 及警告，包含 anchor 的來源座標、匹配位置、相關分數、候選差距、採用起點／比例及原因。現有兩個 locator 入口遇到 prepared metadata 時自動使用新方法，並可透過 `diagnostics` 取得 records。沒有 prepared metadata 的原始音訊保留既有行為，以維持 0 秒流程相容性；新門檻尚未套用到所有歷史音訊。

主 CLI 與 `regenerate_srt_from_export.py` 將 records 傳入字幕 pipeline；不再為退回頁借用相鄰頁間距或全簡報平均比例。分段入口共用定位邏輯及警告，只將有可靠頁首的頁面列為切點候選，並提醒音訊起點不等於精確畫面轉場。

## Anchor 選取

1. 以準備 metadata 的原始解碼時長限制搜尋來源區間，排除追加靜音；核對實際衍生時長與原始時長＋补秒差異不超過 0.3 秒。不符時標示 metadata 錯誤並退回。
2. 以 50 ms RMS 區塊排除原本已有的頭尾靜音；至少需要 0.25 秒有效訊號。這是訊號偵測，不是語音辨識。
3. 先使用最多 8 秒的頭尾片段。弱匹配時最多再嘗試 2 秒、0.5 秒，降低細微播放速度差對長片段波形相關的影響；模糊匹配不藉由縮短片段強行接受。
4. 每次搜尋都限制在預測位置附近的既有搜尋窗口內，沒有無限擴大搜尋。頭尾模板重疊時不估計獨立比例。

## 品質與時間映射

使用局部正規化相關，避免音量較大的無關片段主導結果。目前最低相關分數 0.20；排除最佳點附近 ±0.10 秒後，最佳候選須比其他候選高至少 0.05。有效兩點估計比例須在 0.98～1.02，並通過位置／順序檢查。這些為初始保守門檻，已通過合成與 AAC 對照測試，仍需以真機語音資料評估誤判與退回率，未新增門檻 CLI。

比例使用兩個 anchor 在來源和影片的相對距離計算，起點由來源座標反推。舉例原始 30 秒、補 4 秒，來源第 22～30 秒 anchor 的匹配终點不會被當成第 34 秒。相容 API 的 end 是由映射推算的完整媒體端點，並非觀測到靜音終點。

## 失敗政策與影響

| 狀態 | 採用方式 | 影響 |
|---|---|---|
| `matched` | 頁首、頁尾皆可靠，使用頁內映射 | 仍須抽查，分數不等於同步保證 |
| `head_only` | 可靠頁首，頁內比例 1.0 | 長旁白尾端可能偏移；短音訊亦會明確標示此狀態 |
| `predicted` | 原始累計預測位置，頁內比例 1.0 | 整頁可能偏移，需人工檢查 |
| `silent` | 無音訊頁，沿用預設時長 | 保留後续預測 offset，不生成旁白字幕 |

額外全域係數在局部映射完成後套用一次，也一致套用預測退回頁。警告中的檢查位置以未校正影片座標顯示；records 的採用起點及比例已包含全域係數，raw anchor 匹配座標不變。

下一頁預測始終累計完整媒體長度（包含補秒），不受遭拒絕的匹配污染；後續頁獨立重新定位，因此可以恢復實測。連續預測仍可能累積偏移。若來源無法解碼，以既有預設頁面時長前進並警告，無法保證後續搜尋窗口仍涵蓋真實位置。

新 records 路徑輸出字幕前，檢查非有限、負值、零／負時長、毫秒捨入後零時長、時間倒退／重疊及超出影片音軌時長的情況。非法候選拋出 `SubtitleTimingError`，不覆寫既有 SRT，也不以預測版冒充成功；主 CLI 明確回報並保留已匯出的影片。時間上合法的退回候選仍可輸出，需人工核對。

## 代價與驗證

局部能量正規化及最多三種片段長度增加運算；每次只在固定窗口處理，沒有額外 TTS 或 PowerPoint 匯出。保守門檻可能增加人工檢查頁數，特別是短音訊、重複語句、背景音與高度伸縮音訊。完整音軌仍沿用原實作載入記憶體，多小時影片的記憶體最佳化不屬本階段。

測試涵蓋 1／4／8／10 秒補白、原始尾端靜音、短旁白、純靜音、重複匹配、細微時間伸縮、尾端損壞、連續失敗後恢復、metadata 不符、全域係數只套用一次、跨頁重疊、非法字幕不覆寫，以及真實 ffmpeg AAC 封裝對照。PowerPoint 語音完整性與大型簡報時間誤差仍待最後真機驗收。
