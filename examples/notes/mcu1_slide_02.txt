MCU 簡介
各位同仁，歡迎來到 MCU Fundamentals Training Program 第一週課程。
在正式開始之前，我想先請大家思考一個問題。
每天從早上起床開始，我們會接觸多少電子產品？
手機、智慧手錶、咖啡機、冷氣、洗衣機、汽車、門禁系統、工廠設備、網路設備，甚至辦公室裡的印表機，都屬於我們生活的一部分。
這些產品外觀看起來完全不同，功能也各不相同。
但是，它們卻有一個共同點。
那就是，它們背後幾乎都有一顆 MCU，也就是 Microcontroller Unit，微控制器。
很多人第一次接觸 MCU，容易把它理解成一顆 CPU，或是一顆 IC。
其實，這樣的理解還不夠完整。
MCU 真正的重要性，不只是它是一顆晶片，而是它扮演了整個 Embedded System 的控制核心。
它負責接收資訊、分析狀態、做出判斷，再控制整個系統完成各種工作。
因此，在這一週的課程裡，我們不是要學習如何撰寫 MCU 程式，也不是學習特定廠商的 MCU。
而是希望建立一個共同的系統觀念。
無論您未來負責的是電源管理、感測器、通訊模組、類比元件，甚至其他產品線，都能了解 MCU 在整個系統中的角色，建立 Embedded System 的共同技術語言。
接下來，就讓我們從最基本的概念開始，認識 MCU 為什麼會成為嵌入式系統最重要的控制核心。

首先請看畫面的中央。
可以看到一顆 MCU 位於整個架構的中心。
四周則連接了四個重要的功能模組。
這張圖其實想表達一件非常重要的事情。
MCU 並不是單獨存在，而是整個系統的協調者。
它就像人體的大腦。
真正讓產品運作的，不是只有大腦，而是大腦與眼睛、耳朵、神經、肌肉共同合作。
MCU 在嵌入式系統中，也是相同的概念。

首先來看左上角的 Power。
任何電子產品都需要電源。
沒有電源，再好的 MCU 也無法運作。
Power 不只是提供電力而已。
它還包括電壓轉換、供電管理、低功耗控制，以及電源保護等工作。
例如，一台智慧家電可能需要把市電轉換成 MCU 所需要的 3.3V 或 5V 電源。
而穿戴式裝置則需要盡可能降低耗電，延長電池使用時間。
因此，Power 與 MCU 幾乎是密不可分的。

接著看左下角的 Sensor。
如果把 MCU 比喻成大腦，那麼 Sensor 就像人體的感官。
人類需要透過眼睛看見世界、耳朵聽見聲音、皮膚感受溫度。
同樣地，MCU 也需要透過各種 Sensor，才能知道外面的世界發生了什麼事情。
例如：
溫度感測器可以量測環境溫度。
光線感測器可以偵測環境亮度。
壓力感測器可以監控設備運作狀態。
加速度感測器可以知道產品是否移動。
這些感測器會持續收集資訊，再交由 MCU 分析。
所以我們可以說，Sensor 提供的是系統的「眼睛」與「耳朵」。

再來看右上角的 Connectivity。
今天的電子產品，很少只是單機運作。
很多設備都需要彼此交換資料。
例如：
手機控制家電。
工廠設備回傳資料到雲端。
車輛彼此交換資訊。
智慧家庭中的設備互相連線。
這些都需要 Connectivity。
Connectivity 包含各種通訊介面，例如 UART、SPI、I²C、USB，以及 Wi-Fi、Bluetooth、Ethernet 等無線或有線通訊技術。
MCU 透過這些通訊介面，不只是與其他 IC 溝通，也能與整個系統甚至雲端平台建立連線。
所以，Connectivity 就像 MCU 與外界溝通的橋樑。

最後是右下角的 Software。
很多人以為買到一顆 MCU，產品就會自己運作。
其實並不是。
真正決定產品功能的是 Software。
MCU 提供的是硬體平台。
Software 則告訴 MCU：
什麼時候讀取感測器？
什麼時候控制馬達？
什麼時候開啟 LED？
收到資料後如何分析？
遇到異常又該如何處理？
因此，同樣一顆 MCU，只要更換不同的 Software，就可以變成完全不同的產品。
例如，可以是洗衣機控制器，也可以是智慧門鎖、血壓計，甚至工業控制器。
這也是 Embedded System 最有趣的地方。

接著請看畫面下方中央。
這裡有一句話，非常值得大家記住。
無論產品線為何，FAE 在客戶系統設計、方案整合與技術支援過程中，都將與 MCU 發生關聯。
這也是這門課最重要的目的。
各位目前可能負責的是不同產品線。
有人負責 Power。
有人負責 Sensor。
有人負責 Connectivity。
有人負責 Analog。
表面上看起來，每個人的產品都不同。
但是到了客戶那裡，這些元件最後都必須與 MCU 整合，才能形成完整的產品。
因此，理解 MCU，不只是了解一顆 IC，而是理解整個系統如何協同運作。

最後請看右側的「學習重點」。
這一週，我們將依序建立五項核心能力。
第一，了解 MCU 的基本概念與系統定位。
第二，理解 MCU 為什麼會廣泛出現在各種電子產品中。
第三，認識 MCU 在產品中的角色與價值。
第四，建立 MCU 的基本運作流程。
最後，希望建立所有 FAE 對 Embedded System 的共同技術語言。
完成這五項能力之後，未來看到任何一套系統架構圖，都能快速判斷 MCU 位於哪裡、負責什麼工作，以及它如何與其他元件協同合作。

站在 FAE 的角度，這一頁最重要的收穫，不只是知道 MCU 是什麼，而是開始建立「系統」的觀點。
未來當客戶介紹產品架構時，您看到的不應只是單一顆 IC，而是整個系統之間的互動關係。例如，感測器如何將資料送給 MCU、MCU 如何透過軟體做出決策、再透過通訊介面與其他設備交換資料，最後控制整個產品運作。
因此，無論您負責哪一條產品線，都需要理解 MCU，因為它幾乎都是客戶系統的核心控制單元。當您具備這樣的系統思維，就能更有效地協助客戶分析需求、整合方案，並提供更完整的技術支援。

請再看畫面下方的重點摘要。
今天我們先建立了一個最重要的觀念。
MCU 並不只是 CPU，也不只是控制器，而是 Embedded System 的核心控制單元。
它整合了 CPU、Memory 與各種 Peripheral，並與 Power、Sensor、Connectivity 以及 Software 密切合作，共同完成資料擷取、運算分析、控制輸出與系統管理等工作。
希望大家先記住一件事：理解 MCU，就是理解整個 Embedded System 如何運作。
接下來，我們將從生活中的各種電子產品開始，看看 MCU 究竟存在於哪些地方，以及它如何默默驅動我們每天所使用的各種智慧裝置。
