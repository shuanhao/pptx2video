Peripheral，MCU 與外界互動的橋樑
各位同仁，前面幾頁課程中，我們已經認識了 CPU、Memory，以及 System Bus。
現在，我們要介紹 MCU 最後一個重要的核心組成──Peripheral，也就是周邊介面。
如果說 CPU 是 MCU 的大腦，Memory 是知識與工作空間，System Bus 是內部高速公路，那麼 Peripheral 就是 MCU 與外部世界互動的橋樑。
沒有 Peripheral，CPU 即使再強大，也無法知道外面發生了什麼事情，更無法控制任何設備。
因此，Peripheral 的存在，就是讓 MCU 真正具備感知、控制與通訊能力，完成各種 Embedded System 的應用。

首先請看畫面左側。
這裡描述了 Peripheral 在 MCU 架構中的角色。
可以看到，CPU 位於左側，外部世界位於右側，而 Peripheral 正好位於兩者之間。
這代表所有來自外部世界的資訊，以及所有送往外部設備的控制命令，都需要經過 Peripheral。
換句話說，Peripheral 並不是獨立工作的元件，而是 CPU 與外部世界之間的重要介面。
CPU 無法直接與感測器、LED、馬達或通訊模組連接，而是透過各種 Peripheral 完成資料交換與控制。

接著請看左下方。
Peripheral 在系統中主要有三項工作。
第一，是感知世界，也就是 Input。
例如按鍵、溫度感測器、光感測器或其他外部訊號，都必須透過 GPIO、ADC 等 Peripheral 進入 MCU。
CPU 才能取得這些資料並開始分析。
所以我們可以說，Peripheral 是 MCU 的眼睛、耳朵，以及接收資訊的入口。

第二，是控制世界，也就是 Output。
當 CPU 完成判斷之後，需要把控制命令送到外部設備。
例如：
點亮 LED。
控制馬達旋轉。
驅動蜂鳴器發聲。
更新顯示器畫面。
這些工作，同樣需要 Peripheral 協助完成。
CPU 不會直接輸出高電流驅動設備，而是透過 GPIO、PWM、DAC 等周邊模組，把控制命令轉換成實際輸出。
因此，Peripheral 也是 MCU 控制世界的重要出口。

第三，是交換資料，也就是 Communication。
現代電子產品，很少是單機運作。
設備之間需要交換資料，甚至連接到雲端。
例如：
手機透過 Bluetooth 與智慧手錶同步。
家電透過 Wi-Fi 上傳資料。
工業設備利用 UART、SPI 或 I²C 與其他控制器交換資訊。
這些資料交換，都依靠各種通訊 Peripheral 完成。
因此，Peripheral 不只是輸入與輸出，更負責讓 MCU 能夠與其他設備建立完整的資料連線。

接著請看畫面中央。
這裡把 Peripheral 的功能整理成三大類。
第一類，是感知世界。
也就是從外部取得資訊。
常見的例子包括按鍵、感測器、訊號輸入，以及光感測器等。
第二類，是控制世界。
CPU 根據判斷結果，透過 Peripheral 控制 LED、馬達、蜂鳴器、顯示器等各種設備。
第三類，是交換資料。
包括 UART、I²C、SPI、CAN 等通訊介面，讓 MCU 能夠與其他裝置或系統進行資料交換。
請注意，這三項功能並不是彼此獨立，而是會同時出現在同一個產品中。
一套完整的 Embedded System，通常會同時包含輸入、輸出與通訊功能。

再請看畫面右側。
這裡列出了 Peripheral 與外界互動的實際例子。
在輸入端，可以看到按鍵、溫度感測器、光感測器等裝置。
它們負責提供環境資訊。
在輸出端，可以看到 LED、馬達、顯示器等設備。
它們依照 MCU 的控制命令完成動作。
而在資料交換方面，則有 Wi-Fi 模組、藍牙模組，以及其他 MCU。
這代表 MCU 並不是孤立存在，而是經常需要與其他晶片或系統協同工作。
因此，不同 Peripheral 的組合，也決定了一顆 MCU 能夠應用在哪些產品。
例如，一顆具有豐富 ADC 的 MCU，適合感測應用。
一顆具備多組 UART、SPI 或 CAN 的 MCU，則更適合工業控制或車載系統。
所以，Peripheral 的配置，也是 MCU 選型時非常重要的考量因素。

站在 FAE 的角度來看，理解 Peripheral 的價值，不只是知道它有哪些功能，更重要的是能快速判斷客戶真正需要哪一種周邊介面。
例如，客戶需要大量感測器輸入，就要確認 ADC、GPIO 是否足夠。
如果需要控制多顆馬達，就要評估 PWM 的數量。
若產品需要高速資料交換，就要確認是否具備 SPI、USB 或 CAN 等通訊介面。
因此，很多 MCU 的選型工作，其實並不是先看 CPU 效能，而是先確認 Peripheral 是否符合系統需求。
這也是 FAE 在方案設計與技術支援時，最常遇到的工作之一。

最後請看畫面下方的重點摘要。
Peripheral 是 MCU 與外部世界互動的重要介面。
它負責三項核心任務：
第一，接收外部資訊。
第二，控制外部設備。
第三，與其他裝置交換資料。
並且透過 System Bus 與 CPU 協同合作，共同完成各種 Embedded System 的控制任務。
請記住一個核心觀念：
CPU 負責思考，Memory 提供程式與資料，System Bus 負責傳輸，而 Peripheral 則負責讓 MCU 真正看見世界、影響世界，並與世界連接。
