MCU 作為小型電腦
各位同仁，前面幾頁課程中，我們已經分別認識了 CPU、Memory、System Bus，以及 Peripheral。
現在，我們把這些元件重新組合起來，看看它們如何共同運作，形成一套完整的 MCU 系統。
很多人第一次接觸 MCU 時，都會把它理解成一顆晶片。
其實，從系統架構的角度來看，MCU 更像是一台專門負責控制工作的「小型電腦」。
它不像我們平常使用的個人電腦那樣追求高效能、多工運算，而是針對嵌入式控制任務進行最佳化設計。
這也是本頁希望建立的重要觀念。

首先請看畫面左側。
這裡比較了一般電腦與 MCU 的差異。
一般電腦，例如桌上型電腦或筆記型電腦，主要目的是提供通用運算能力。
它可以同時執行文書處理、瀏覽網頁、播放影片、執行大型應用程式，甚至同時開啟許多不同的工作。
因此，它需要大量的記憶體、高效能處理器，以及 Windows、macOS 或 Linux 等完整作業系統。
此外，還要搭配螢幕、鍵盤、滑鼠等完整的人機介面。

再來看看 MCU。
MCU 的定位完全不同。
它不是為了執行各種應用程式，而是專門完成一項或少數幾項固定的控制任務。
例如：
控制洗衣機的洗程。
控制冷氣的溫度。
控制汽車儀表板。
控制智慧門鎖。
控制工廠設備。
因此，MCU 通常使用容量較小的記憶體，執行輕量化的 Firmware，不需要完整作業系統，也不需要複雜的人機介面。
它最大的特色，就是低功耗、體積小、成本低，而且能夠長時間穩定運作。
所以，我們可以把 MCU 看成是一台專門負責控制工作的迷你電腦，而不是縮小版的個人電腦。

請注意畫面下方的重點。
MCU 並不是一般電腦的簡化版本，而是一種針對控制任務最佳化設計的嵌入式控制器。
它們雖然都具有 CPU、記憶體與運算能力，但設計目標完全不同。
了解這一點，有助於未來理解 MCU 的產品定位與選型思維。

接著請看畫面中央。
這裡整理了 MCU 最基本的運作流程。
整個流程可以濃縮成三個步驟：
Input、Process，以及 Output。
首先，由感測器或其他外部設備提供輸入資訊。
接著，MCU 透過 CPU 執行程式，並利用 Flash 與 SRAM 提供程式與資料，完成分析與判斷。
最後，再把控制結果輸出到 LED、馬達、蜂鳴器等外部設備。
這就是我們前面介紹過的控制循環。
不同的是，現在我們把 CPU、Memory 與 Peripheral 放回同一個架構裡，就更容易理解它們彼此之間如何合作。

請特別注意 Memory 的角色。
Flash 保存的是程式碼。
每次開機時，CPU 都是從 Flash 取得程式開始執行。
而 SRAM 則提供執行期間的工作空間。
所有運算資料、變數與暫存結果，都放在 SRAM 裡。
因此，CPU、Flash 與 SRAM 並不是各自獨立，而是彼此緊密合作，共同完成每一次控制任務。

接著請看畫面右側。
可以看到，MCU 幾乎存在於各種電子產品之中。
例如家電產品。
冷氣、洗衣機、微波爐、電風扇，都需要 MCU 控制運作流程。
在汽車電子方面，包含車身控制、儀表板、引擎管理與安全系統，也都有大量 MCU。
智慧手錶、健康手環等穿戴式裝置，同樣需要 MCU 持續監測感測器並管理低功耗運作。
工業控制設備，例如機器手臂、馬達控制器與設備監控，也都以 MCU 作為控制核心。
此外，智慧家庭、物聯網裝置，以及各種消費性電子產品，也都廣泛採用 MCU。
由此可見，MCU 雖然不像 PC 那樣引人注意，但它早已深入我們每天接觸的各種產品。

再請看畫面下方左側。
這裡利用一個簡單的流程，比喻 MCU 的工作方式。
感測器取得環境資訊。
MCU 進行判斷與控制。
最後控制 LED、馬達等輸出設備。
這其實就是所有嵌入式系統最基本的控制模型。
無論產品是洗衣機、智慧門鎖，還是工業控制器，本質上都遵循相同的控制流程。

旁邊則把 MCU 比喻成一台迷你電腦。
CPU 就像大腦，負責思考與決策。
Memory 提供記憶能力，保存程式與資料。
Peripheral 則像人體的感官與四肢，負責感知外部世界並控制外部設備。
System Bus 則像神經系統，負責在各個模組之間快速傳遞資訊。
當這四個部分協同運作時，一套完整的 MCU 系統就建立起來了。

站在 FAE 的角度，建立這個「小型電腦」的觀念非常重要。
因為未來面對客戶時，不應只把 MCU 視為一顆 IC，而要把它看成一個完整的控制平台。
當客戶提出需求時，我們需要思考的是：
需要多少運算能力？
需要多少 Flash 與 SRAM？
需要哪些 Peripheral？
是否符合功耗、成本與即時性的要求？
這些都是 MCU 選型與方案規劃時的重要依據。

最後請看畫面右下方的重點摘要。
MCU 並不是通用電腦，而是整合 CPU、Memory、System Bus 與 Peripheral 的嵌入式控制器。
它透過感知、處理與控制的流程，高效率完成各種專用控制任務。
請記住今天最重要的一個觀念：
MCU 可以被視為一台專門負責控制工作的「小型電腦」，它將運算、記憶、資料傳輸與周邊控制整合於單一晶片，讓電子產品能夠持續感知環境、做出判斷，並控制外部世界。
下一頁，我們將把本週介紹的所有核心元件重新整合，從系統角度完整回顧 MCU 的架構與各模組之間的協同運作，建立完整的 MCU Architecture 觀念。
